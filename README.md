# CRISPO — Brand Redesign Site

Animated marketing site for the **CRISPO** snack brand redesign.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Framer Motion
- Fredoka + Plus Jakarta Sans

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Design

Reference and mockups live in `/design`. Product and hero imagery are in `/public/images`.
